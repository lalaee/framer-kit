# House rules (user preferences that override defaults)

1. **Build in Figma**, in the same file as the source, using local variables and components. Write code only when explicitly asked.
2. **Every icon comes from Iconly** (Light style), normalized to the source icon size and weight. There are no other icon sources.
3. **Icon sizes: 10 / 12 / 16 / 20. Below 16px the stroke is 0.75.**
4. **Labels and most UI text are Semi Bold.** Body copy is Medium. Match how strong the source looks, and don't go lighter.
5. **Nav icons are small (12px) and navs have an inset.** Every side nav gets the same inset, including project and secondary navs.
6. "Continue with Google" and other Inverse/white buttons use the same label weight as Primary.
7. **Never reskin** an existing app. Work out what it's for, then design it from scratch with the library.
8. **Use no-preview thumbnails** for every thumbnail unless real images are supplied.
9. **Rails are vertical with labels.** Design a panel for each area.
10. Never commit secrets. The Iconly key lives in `ICONLY_API_KEY`.
